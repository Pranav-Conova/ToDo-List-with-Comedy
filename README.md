## 📝 Project Title: ToDo List with Comedy 😂🎯

### 📌 Description:
**ToDo List with Comedy** is a light-hearted and interactive web-based task manager built with **Django** that adds a twist of humor to your daily productivity. Every task comes with a sprinkle of comedy — auto-generated funny descriptions that make even the most boring chores feel like a joke worth remembering!

The app allows users to:
- ✅ Add tasks with titles and descriptions  
- 😆 View a funny AI-generated comedy line for each task  
- ✔️ Mark tasks as completed with stylish animated checkboxes  
- ✏️ Edit or 🗑️ delete tasks directly from the list  
- 🧠 Enjoy a vibrant UI with a floating emoji background and rotating comedy messages  

Whether you're organizing your day or just want to giggle while planning your week, this ToDo app ensures productivity meets laughter.

### 🔧 Tech Stack:
- **Backend:** Django (Python)  
- **Frontend:** HTML, CSS, JavaScript  
- **Templating Engine:** Django Templates  
- **Database:** SQLite (default Django DB)  
- **Extra Sparkle:** Fun UI animations, emoji floaters, and themed styling with Comic Sans charm 😎
